# Security policy

MegaGlitch 0.9.4 is a developer beta. Security fixes target the latest source revision; older snapshots are not supported.

For vulnerabilities, use the repository host's private security-advisory or vulnerability-reporting feature. Do not include credentials, private media, device identifiers, or exploit details in a public issue.

For a useful report, include the affected revision, operating system, Python version, reproduction steps, impact, and whether the issue requires untrusted project, preset, shader, Lua, media, or device input.
